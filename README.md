API Gateway (Modupay Ekosistemi)
Bu proje, Modupay mikroservis mimarisinde gelen istekleri uygun servisçiklere yönlendiren ve yönlendirme (routing) kurallarını yöneten Spring Cloud Gateway bileşenidir.

Özellikler
Tüm gelen istekler için tek bir ana giriş kapısı (Single Entry Point) sağlar.

Eureka Server ile entegre çalışarak servisleri dinamik olarak keşfeder.

Kurulum ve Çalıştırma
Projeyi klonlayın:

Bash
git clone https://github.com/endlessloop88/api-gateway.git
Maven bağımlılıklarını yükleyin ve projeyi çalıştırın.
